## Usage

The component takes the items as children. Any element works.

```tsx
const IMAGES = [
    "https://picsum.photos/seed/atelier-1/1200/800",
    "https://picsum.photos/seed/atelier-2/1200/800",
    "https://picsum.photos/seed/atelier-3/1200/800",
    "https://picsum.photos/seed/atelier-4/1200/800",
    "https://picsum.photos/seed/atelier-5/1200/800",
]

<ScatteredScroll>
    {IMAGES.map((src) => (
        <img key={src} src={src} alt="" className="aspect-[5/7] w-[30vw] object-cover" />
    ))}
</ScatteredScroll>
```

Works best with smooth scrolling. You can add [Smooth Scroll](/docs/components/primitive/smooth-scroll) at the root for that:

```tsx title="Root layout"
import { SmoothScroll } from "@/components/smooth-scroll";

export default function RootLayout({ children }) {
  return <SmoothScroll>{children}</SmoothScroll>;
}
```

### Scroll length

By default the component creates the scroll section for you. `scrollLength` sets how many viewport heights of scrolling the effect takes:

```tsx
<ScatteredScroll scroll={{ scrollLength: 4 }}>
  <img src="/1.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
  <img src="/2.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
  <img src="/3.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
</ScatteredScroll>
```

### Custom scroll section

If you need control over the layout, you can also build the section yourself and pass it as `track`:

```tsx
const trackRef = useRef<ComponentRef<"div">>(null)

<div>
  <div className="h-screen" />

  <div ref={trackRef} className="relative h-[300vh] overflow-x-clip">
    <div className="sticky top-0 flex h-screen items-center justify-center gap-2">
      <ScatteredScroll scroll={{ track: trackRef }}>
        <img src="/1.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
        <img src="/2.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
        <img src="/3.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
      </ScatteredScroll>
    </div>
  </div>

  <div className="h-screen" />
</div>
```

## API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | The items to animate. Any JSX element allowed. Required. |
| `scroll` | `ScrollMode` | `{ scrollLength: 2 }` | Scroll behavior, one of the modes below. |

### Scroll modes

| Mode | Description |
| --- | --- |
| `{ scrollLength: number }` | Creates the scroll section and runs the effect over that many viewport heights of scrolling. |
| `{ track: RefObject<HTMLElement \| null> }` | Drives the animation from your own scrolled section instead of the built-in one. |
