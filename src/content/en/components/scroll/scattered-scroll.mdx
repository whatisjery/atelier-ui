## Usage

The component takes the items as children. Any element works.

```tsx
<ScatteredScroll>
  <img src="/1.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
  <img src="/2.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
  <img src="/3.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
</ScatteredScroll>
```

Works best with smooth scrolling, you can add [Smooth Scroll](/docs/components/primitive/smooth-scroll) at the root for that:

```tsx title="Root layout"
import { SmoothScroll } from "@/components/smooth-scroll";

export default function RootLayout({ children }) {
  return <SmoothScroll>{children}</SmoothScroll>;
}
```

### Custom scroll section

By default the component creates the scroll section for you. If you need control over the layout, you can also build the section yourself and pass `scrollTargetRef`:

```tsx
const scrollTargetRef = useRef<ComponentRef<"div">>(null)

<div>
  <div className="h-screen" />

  <div ref={scrollTargetRef} className="relative h-[500vh] overflow-x-clip">
    <div className="sticky top-0 flex h-screen items-center justify-center gap-2">
      <ScatteredScroll scrollTargetRef={scrollTargetRef}>
        <img src="/1.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
        <img src="/2.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
        <img src="/3.webp" alt="" className="aspect-[5/7] w-[30vw] object-cover" />
      </ScatteredScroll>
    </div>
  </div>

  <div className="h-screen" />
</div>
```

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | The items to animate. Any JSX element allowed. |
| `scrollDistance` | `string` | `"500vh"` | How much scrolling the effect takes. Any CSS height. Ignored when `scrollTargetRef` is set. |
| `scrollTargetRef` | `RefObject<HTMLElement \| null>` | — | External scrolled section driving the animation. Disables the built-in section. |
