<Collapsible title="Usage">

Pass the trail items as children. They spawn along the cursor path.

```tsx
const IMAGES = [
    "https://picsum.photos/seed/atelier-1/1200/800",
    "https://picsum.photos/seed/atelier-2/1200/800",
    "https://picsum.photos/seed/atelier-3/1200/800",
]

<ImageTrail>
    {IMAGES.map((src) => (
        <img key={src} src={src} className="w-32 h-32 object-cover rounded-xl" alt="" />
    ))}
</ImageTrail>
```

</Collapsible>

---

<Collapsible title="API" defaultOpen>

| Name           | Type        | Default | Description    |
| -------------- | ----------- | ------- | ------------- |
| `children`       | `ReactNode` | —       | Items to cycle through as the cursor moves. Required.|
| `spawnDistance`  | `number`    | `76`    | Distance in pixels before spawning an item.|
| `driftAmount`    | `number`    | `36`    | How far each item drifts from its spawn point in px.|
| `removeDelay`    | `number`    | `1.0`   | Seconds before a spawned item is removed.|

</Collapsible>
