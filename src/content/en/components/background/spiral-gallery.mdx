<Collapsible title="Usage">

All WebGL components render through [one shared canvas](/docs/getting-started/how-it-works).
Add the `WebglProvider` once at the root of your app:

```tsx title="Root layout"
import { WebglProvider } from "@/components/webgl-provider/webgl-provider";

export default function RootLayout({ children }) {
  return <WebglProvider>{children}</WebglProvider>;
}
```

Then use it anywhere in your app:

```tsx
const ITEMS = Array.from({ length: 20 }, (_, i) => ({
    src: `https://picsum.photos/seed/atelier-${i + 1}/1200/800`,
    alt: "",
}))

<SpiralGallery items={ITEMS} className="fixed inset-0" />
```

You can pass fewer images than `tileCount`.
The list repeats until every tile on the tube has one.

### Scroll input

By default the carousel moves with the wheel.
If you want it to use the real page scroll, set `input="scroll"`:

```tsx
<SpiralGallery items={ITEMS} input="scroll" className="fixed inset-0" />
```

### Post-processing

The gallery renders through a [WebGL Scene](/docs/components/primitive/webgl-scene) layered above other content.
Set `mode="texture"` to render it into post-processing instead, so effects like `FluidDistortion` apply to the spiral:

```tsx
<FluidDistortion />

<SpiralGallery items={ITEMS} mode="texture" className="fixed inset-0" />
```

<Collapsible title="API" defaultOpen>

| Name | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `items` | `SpiralGalleryItem[]` | - | The images to show, each one as `{ src, alt }`. They repeat to fill `tileCount`. Required. |
| `radius` | `number` | `5` | Radius of the tube the images travel around, in world units. |
| `tileHeight` | `number` | `2.45` | Height of each image, in world units. |
| `tileAspect` | `number` | `1.5` | Width-to-height ratio of each image. Images are cropped to fit. |
| `tileCount` | `number` | `16` | Number of images on screen at once. Items repeat if there are fewer. |
| `verticalSpacing` | `number` | `0.95` | Vertical distance between one image and the next. |
| `turnAngle` | `number` | `46` | Angle between one image and the next around the tube, in degrees. |
| `tileRotation` | `number` | `1` | How much each image rotates on its own vertical axis as it orbits. `1` keeps images flat against the tube, `0` faces them all the same way. |
| `cornerRadius` | `number` | `0.05` | Corner rounding of each image, in world units. |
| `curve` | `number` | `0.1` | How much each image bends inward across its width. |
| `autoScroll` | `number` | `0.1` | Speed the carousel scrolls on its own, with no input. |
| `easing` | `number` | `0.1` | How long the scroll takes to settle, in seconds. Higher is slower. |
| `input` | `"wheel" \| "scroll" \| "none"` | `"wheel"` | Where scrolling comes from. `"wheel"` captures the wheel over the gallery, `"scroll"` follows the page scroll, `"none"` leaves only dragging. |
| `inputSpeed` | `number` | `1.1` | Multiplier on wheel and drag distance. Higher moves further per gesture. |
| `drag` | `boolean` | `true` | Allow dragging the carousel with the pointer. |
| `scrollSpread` | `number` | `0.5` | Extra angle added between images while scrolling. `0` keeps the spacing fixed. |
| `scrollGrowth` | `number` | `0.65` | How much the radius and vertical spacing grow while scrolling. |
| `lensBlur` | `number` | `0.4` | Strength of the lens pass: edge blur, RGB split and the fisheye bulge that swells while an image opens. `0` disables it; higher values blur more toward the edges. |
| `autoScale` | `boolean` | `true` | Shrink the spiral on narrow viewports so it stays inside the container. |
| `scale` | `number` | `1.3` | Overall size of the spiral, applied on top of `autoScale`. |
| `reveal` | `boolean` | `true` | Play the mount animation, where the images start as a flat band and wrap onto themselves into the tube, turning once around. |
| `revealDuration` | `number` | `2` | How long the mount animation takes, in seconds. |
| `focusDuration` | `number` | `2.1` | How long the click-to-focus unwinding takes, in seconds. Sliding between two open images takes 40% of it. |
| `focusScale` | `number` | `0.7` | Share of the container height the open image covers, from `0` to `1`. Lower it for more room around the row. |
| `className` | `string` | - | Classes for the interaction surface the gallery renders into. Sizes the gallery, any container size works. |

It also forwards [WebGL Scene](/docs/components/primitive/webgl-scene) props: `mode`, `priority`, `zIndex`, `transparent`, and `autoReflow`.
